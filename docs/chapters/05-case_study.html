3.8 Case study: Object realisation of EAT

Author
Affiliation

Vladimir Buskin

Catholic University of Eichstätt-Ingolstadt

Abstract
This handout presents a complete analysis of categorical corpus data, from the research question to the write-up. Using annotated concordance lines of the verb EAT from ICE-GB, it combines descriptive statistics, the chi-squared test, Fisher’s exact test, effect sizes, residuals and configural frequency analysis.

Overview

This unit shows what a simple, but complete corpus-linguistic analysis can look like. It brings together the steps covered in the previous units:

  • obtaining and annotating the data (see 2.4 Data annotation),
  • describing the data with frequency tables and plots (see 3.3 Descriptive statistics), and
  • testing hypotheses about the relationship between two categorical variables (see 3.4 Hypothesis testing and 3.5 Chi-squared test).

Research question and hypotheses

In 2.4 Data annotation, we asked whether grammatical aspect influences whether the direct object of eat is realised or omitted. Before examining aspect (see the exercises), it is worth checking whether object realisation also varies across registers. If, for instance, objects were omitted much more often in conversation than in writing, register would have to be taken into account when interpreting any other effect.

We will therefore test the following hypotheses for the variables object_realisation (yes/no) and medium (spoken/written):

  • \(H_0:\) Object realisation and medium are independent of each other.
  • \(H_1:\) Object realisation and medium are not independent of each other.

The same hypotheses will be tested for the more fine-grained text_category (S1A, S1B, …, W2F).

Inferential analysis

Object realisation and medium

For a 2 \(\times\) 2 table with sufficiently large expected frequencies, we can use the \(\chi^2\) test. By default, chisq.test() applies Yates’ continuity correction to 2 \(\times\) 2 tables (see 3.5 Chi-squared test).

sw_test <- chisq.test(obj_sw_freq)

Post-hoc analyses

A significant test result tells us that the variables are associated, but not where the association comes from. Two approaches can help to identify the relevant cells.

Residuals

The Pearson residuals \((O - E)/\sqrt{E}\) show which cells deviate most from the expected frequencies. In an association plot, bars above the line indicate cells with more observations than expected, bars below the line cells with fewer observations than expected. The area of each bar is proportional to the difference between observed and expected frequencies.

# Pearson residuals
round(chisq.test(obj_reg_freq)$residuals, 2)

Configural Frequency Analysis

Configural Frequency Analysis (CFA) tests each combination of values (a configuration) for whether it occurs significantly more often (type) or less often (antitype) than expected. Since every configuration is tested separately, the \(p\)-values have to be corrected for multiple testing, e.g., with the Bonferroni correction.

# Convert the contingency table to a data frame with one row per configuration
reg_config_df <- as.data.frame(obj_reg_freq)

# The first two columns contain the configurations, the Freq column the corresponding counts
reg_configs <- as.matrix(reg_config_df[, 1:2])
reg_counts <- reg_config_df$Freq

# Perform CFA with Bonferroni correction
reg_cfa_output <- cfa(reg_configs, reg_counts, bonferroni = TRUE)

# Print the full output with reg_cfa_output, or only the most relevant columns:
reg_cfa_output$table[, c("label", "n", "expected", "z", "p.z", "sig.z")]

The relevant columns are the observed frequency n, the expected frequency, the test statistic z1 with its \(p\)-value p.z, and sig.z, which indicates whether a configuration is significant after the Bonferroni correction. Since z is always positive in this output, we have to compare n and expected to determine whether a significant configuration is a type or an antitype.

1 The \(z\)-score corresponds to the absolute value of the Pearson residual, \[ z = \frac{|\text{observed} - \text{expected}|}{\sqrt{\text{expected}}}, \] which approximately follows a standard normal distribution under \(H_0\). The approximation is poor for small expected frequencies, so the results should be interpreted with caution in sparse tables like this one.

In our data, the following configuration(s) are significant after Bonferroni correction: yes W2B (type; observed = 14, expected = 6.18, \(z = 3.15\)).

Reporting the results

In a paper or report, the results could be described as follows. Note that the report contains the test statistic, the degrees of freedom, the \(p\)-value and the effect size, so that readers can evaluate the results themselves.

Object realisation of eat was compared across spoken and written texts in ICE-GB (n = 102). Objects were realised in 39.7% of the spoken and 52.9% of the written attestations. According to a \(\chi^2\) test with Yates’ continuity correction, this difference is not statistically significant (\(\chi^2(1) = 1.12\), \(p = 0.29\), Cramér’s \(V = 0.13\)). A Fisher’s exact test indicates a significant association between object realisation and the more fine-grained text categories (\(p < 0.001\)).

Limitations

This analysis is deliberately simple. A more thorough study would have to address at least the following issues:

  • Non-independence: Several hits may come from the same text or speaker. The tests used here assume that all observations are independent of each other (see 4.3 Mixed-effects regression).
  • Sparse data: Many text categories contain very few hits, which makes the fine-grained comparison unreliable.
  • Several variables at once: Register and aspect might both influence object realisation. Testing each variable separately cannot disentangle their effects, which requires a multivariate model such as logistic regression.
